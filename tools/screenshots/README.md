# Скриншоты Web UI

Генератор открывает текущие `index.html`, `style.css` и `app.js` в Chromium.
API подменяется демонстрационными ответами: настоящие аккаунты, сервер Encounter
и LLM не используются. Получаются три PNG для главного README: общий вид,
чат в светлой теме и тот же чат в тёмной теме.

```sh
cd tools/screenshots
npm ci
npx playwright install chromium
npm run render
```

На Linux для установки системных зависимостей браузера:
`npx playwright install --with-deps chromium`.
Нужен доступ к Google Fonts для загрузки тех же шрифтов, что использует Web UI.

Workflow `Web UI screenshots` запускается при изменении web-ui, генератора
или самого workflow. В PR изображения доступны как artifact; после изменения
`main` workflow коммитит обновлённые PNG, поэтому картинки в README обновляются
автоматически. Требуется разрешение репозитория на push от `GITHUB_TOKEN` в
`main`; правила защиты ветки могут его запрещать. При таком запрете push явно
завершится ошибкой, а изображения останутся доступны в artifact.

Для изменения содержимого примеров отредактируйте фикстуры в `render.mjs`.
Генератор завершается ошибкой при неизвестном API-запросе, ошибке JavaScript,
незагруженном шрифте или видимом уведомлении об ошибке.

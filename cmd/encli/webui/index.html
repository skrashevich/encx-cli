      Настройка encli

      Три шага до первого запроса агенту

      1. 1 Начало
      2. 2 Модель
      3. 3 Движок
      4. 4 Вход

      encli — агент для работы с квестами en.cx: читает задания, ведёт переписку и выполняет действия на сайте вместо вас.

      Мастер проходит три шага и сохраняет настройки локально. Любой шаг можно пропустить и вернуться к нему позже.

      1. Модель — как агент подключается к языковой модели.
      2. Движок — с каким API домена работать.
      3. Вход — учётная запись en.cx для доступа к играм.

      Агент работает на этой машине, без сети и без ключей. Ничего вводить не нужно: модель и библиотеки скачиваются один раз. Маленькая модель по умолчанию заметно слабее облачных — модель можно сменить позже в настройках LLM.

      Вставить redirect URL вручную

      Если браузер открылся на другой машине, скопируйте адрес, на который он перенаправил, и вставьте сюда.

      Подойдёт любой провайдер с OpenAI-совместимым API. Ключ остаётся на этой машине.

      Движок домена

      Логин и пароль нужны, чтобы агент открывал задания от вашего имени. Данные хранятся локально.
